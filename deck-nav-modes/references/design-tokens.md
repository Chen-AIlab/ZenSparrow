# 设计令牌与视觉稳定规范

本文件是全技能的"稳定性底座"：任何模式、任何页面生成时都必须遵守。modes.md 管"页面之间怎么跳"，本文件管"每一页长什么样、多满、多稳"。

## 目录

- 1. 视觉聚焦规范（锚点 / 安全区 / 动效幅度 / 内容重心）
- 2. 字号层级（五级阶梯）
- 3. 间距层级（8pt 刻度）
- 4. 色彩用量（单一强调色 + 灰阶）
- 5. 圆角与阴影
- 6. 单页信息容量上限
- 7. 深浅页节奏

## 1. 视觉聚焦规范

**目的**：翻页/跳页时，观众的视线落点不变，像"镜头锁在三脚架上"。

- **固定锚点**：页眉（chrome）、kicker、大标题在所有正文页必须出现在像素级同一位置——同一骨架类保证，禁止任何一页单独挪动标题区。
- **标题轴**：正文页大标题一律左对齐，基线位置一致；只有封面/收尾/宣言页允许居中或放大破格。
- **底部安全区**：分页圆点/返回按钮占用区域内容不得侵入。linear 模式内容最低处 ≤ `88vh`；有固定返回按钮的页面，内容区左上留出按钮安全距离（模板已内置 `.has-back`）。
- **动效幅度上限**：入场位移 ≤ 24px，时长 400–700ms，缓出曲线（cubic-bezier(0,0,.3,1) 类）；**禁止**缩放弹跳（scale >1.05）、旋转、大幅淡入位移——这些是"镜头晃"的根源。元素按 0.08s 阶梯依次入场，不得整页同时闪入。
- **内容重心**：正文页内容垂直重心落在页面 40–60% 区间（偏上半屏），底部留白给呼吸和安全区；禁止把内容顶满全屏或全部堆在上 1/3。
- **每页一个视觉主角**：一页只允许一个"最重的元素"（一个大标题 / 一组大数字 / 一张主图），其余元素字重、色饱和度都必须低于它。

## 2. 字号层级（五级阶梯）

只允许使用这五级，不允许发明中间值。桌面/投屏基准：

| 级别 | 用途 | 字号 | 字重 |
|---|---|---|---|
| L1 Display | 封面主标题、宣言大字 | `min(5.2vw, 9.4vh)`，投影可至 `min(6.4vw,11.2vh)` | 700（或对应主题规定） |
| L2 页标题 | 正文页大标题 | `min(3.4vw, 6vh)` 或与 L1 同级但每页唯一 | 700 |
| L3 卡标题 / 小标题 | 卡片标题、表格强调列 | 18–22px | 600–700 |
| L4 正文 / 说明 | 段落、卡片描述、表格单元格 | 16–18px | 400–500 |
| L5 meta / 标签 | 页眉、页脚、kicker、图注、分页 | 14px | 500–600，可全大写 + 字距 |

规则：
- **越大越醒目，越小越克制**：级别数字越小，允许的字重越高；L4/L5 禁止用超大字重抢戏。
- 中文标题优先改短，其次降级；三行以上长标题必须改写而不是继续缩字号。
- 14px 是演示场景绝对下限，低于它投屏不可读。
- 数字表格/时间线数字建议等宽数字特性（`font-feature-settings:"tnum"`），防止纵向对比时数字跳动。

## 3. 间距层级（8pt 刻度）

只允许使用 8 的倍数：`8 / 16 / 24 / 32 / 48 / 64 / 96`。对应 CSS 变量 `--sp-1:8px` … `--sp-7:96px`。

- 卡片内边距：24px（紧凑 20px）
- 卡片间距 / 网格 gap：16px
- 页面边距：统一走 `--pad-x` / `--pad-y` 变量，禁止 inline 另写
- 元素垂直间距不足时，优先删内容或拆页，**禁止**用 <8px 的缝隙硬挤

## 4. 色彩用量（单一强调色 + 灰阶）

- 一份材料只有**一个强调色**（accent），用途仅限：kicker、当前状态、重点卡、关键数字、交互 hover。全页强调色面积 ≤ 10%。
- 其余全部走灰阶梯度：纸底 / 浅灰卡片 / 描边灰 / 辅助文字灰 / 主文字墨色。
- 状态色（红/橙/绿）只允许出现在"状态/风险"语义里（如风险等级条、物料状态），不得作装饰。
- 深色页的反白文字用 85–100% 白，辅助文字用 60–75% 白，不用灰色（深底上灰字发糊）。

## 5. 圆角与阴影

- 圆角只有两档：卡片 14–18px、按钮/标签胶囊 99px。禁止 4px、10px 等中间值混用。
- 阴影只有两档：静态轻影 `0 2px 12px rgba(0,0,0,.05)`、hover 浮起 `0 14px 34px rgba(0,0,0,.10)`。禁止彩色阴影、多层阴影。
- 直角设计系统（如 Swiss 风格）除外——但那是"全套替换"，不是混用。

## 6. 单页信息容量上限

超上限 = 拆页，不是缩字号：

| 内容形态 | 上限 |
|---|---|
| 卡片 | ≤ 6 张/页（2×3 或 3×2）；4 张以内最佳 |
| 表格 | ≤ 8 行 × 5 列；超出拆两页或转附录 |
| 时间线节点 | 横向 ≤ 7 个，纵向 ≤ 8 个 |
| 列表条目 | ≤ 7 条，每条 ≤ 2 行 |
| 正文段落 | ≤ 3 段，每段 ≤ 3 行 |
| 每页核心信息点 | **1 个**——一页只讲一件事 |

## 7. 深浅页节奏

- 连续同色调页面 ≤ 3 页；8 页以上的线性 deck 必须有深色页（封面/章节/收尾）制造呼吸。
- 推荐节奏：深（封面）→ 浅×2-3 → 深（章节/宣言）→ 浅×2-3 → 深（收尾）。
- 深色页只放最少内容（标题 + 一句话），它是"换气口"，不是塞内容的容器。

## 8. 每页生成后自检清单

逐页过一遍，全 ✅ 才算完成：

1. 页眉/标题位置与其他页一致（锚点未漂移）
2. 内容最低处在底部安全区之上（linear ≤88vh）
3. 字号全部落在五级阶梯内，无 <14px 文字
4. 间距全部是 8 的倍数，无 inline 边距
5. 强调色只有一处焦点，面积 ≤10%
6. 卡片 ≤6 / 表格 ≤8×5 / 列表 ≤7，单页只讲一件事
7. 动效位移 ≤24px，无缩放弹跳
8. 深浅节奏：同色调连续 ≤3 页
9. 占位文字均为【…】格式或已有编辑注释
10. 浏览器实际截图看过（不是只读代码判断）
